# Автокликер билетов для Windows

Запуск: дважды нажать `start.cmd`. Установка дополнительных программ не нужна.
Предназначен для билетов за игровую валюту без вывода выигрыша.

1. Открой игру в оконном режиме и оставь окно на постоянном месте.
2. Нажми «Записать заново». В игре наведи курсор на первую кнопку и нажми F6.
   F6 сохраняет координаты, но не нажимает кнопку: нажимай игровые кнопки вручную,
   чтобы перейти к следующему шагу, затем снова наводи курсор и нажимай F6.
3. Запиши полный цикл покупки и открытия **одного** билета, включая закрытие
   результата. В конце должен снова отображаться исходный экран покупки.
   Пауза между соседними F6 становится задержкой после предыдущего клика
   (от 1 до 60 секунд); после последней точки пауза составляет 2,5 секунды.
4. Нажми «Завершить запись». Верни игру к исходному экрану.
5. Выбери 1 для проверки. Переключись в игру и нажми F8. Через 3 секунды
   начнутся клики. Если цикл отработал правильно, выбери 20, 30 или 50.
6. Esc останавливает выполнение. Переключение в другое окно также останавливает
   выполнение. После остановки верни исходный экран перед повторным запуском:
   каждый запуск начинает отсчет заново.

Количество означает число повторений записанной последовательности. Программа
не проверяет успешность покупки, баланс или сообщение об отсутствии билетов.
При появлении такого сообщения нажми Esc. Автоматическое распознавание сообщения
требует отдельной настройки по его изображению и в этой версии отсутствует.
Во время работы не перемещай окно и курсор. При смене разрешения, масштаба или
расположения интерфейса запиши точки заново. Сначала проверь один цикл.

Настройка хранится локально в `%LOCALAPPDATA%\TicketClicker\sequence.json`.
Удаление точки нужно сохранить кнопкой «Завершить запись».
Записывай и запускай F6/F8 только в окне игры: программа считает активное окно
целевым. Проверка интерфейса без кликов: `powershell -NoProfile -STA -ExecutionPolicy Bypass -File
ticket-clicker.ps1 -SelfTest`.
